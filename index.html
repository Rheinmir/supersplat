SuperSplat Editor

playcanvas/supersplat

SuperSplat là trình chỉnh sửa 3D Gaussian Splat mã nguồn mở, chạy trên web. Cho phép inspect, edit, optimize và publish 3D Gaussian Splats trực tiếp trên browser — không cần cài đặt, không cần GPU mạnh.

⭐ ~2k stars 📄 MIT license 🔧 TypeScript + PlayCanvas 🌐 superspl.at/editor 🔄 superspl.at/convert

🏗️ Kiến trúc

SuperSplat được xây dựng trên PlayCanvas engine, sử dụng WebGL/WebGPU để render hàng triệu splat realtime. Kiến trúc gồm:

  • Event-driven core — hệ thống events + function registry để module giao tiếp
  • Command pattern — mọi thao tác edit là object có do() / undo(), quản lý bởi EditHistory
  • Async GPU serialization — Promise chain tránh race condition khi GPU readback + undo/redo
  • 8 selection tools — box, lasso, brush, polygon, sphere, flood, eyedropper, rect
  • Multi-format I/O — .ply, .splat, .ksplat, .json import/export
  • i18n từ đầu — 10+ ngôn ngữ qua i18next

🧠 Best practice học được

  • Composition over inheritance — Scene chứa Camera, Grid, Outline, SplatOverlay... thay vì extends
  • Web Workers + PWA — service worker riêng, manifest cho offline capability
  • PCUI component library — UI tách biệt core logic, dùng lại cross-project
  • Rollup multi-entry — build app + service worker, tree-shaking, strip debug code

01 · 3D Capture & Photogrammetry

Từ video điện thoại → splat 3D

Quay vật thể 30s, train 5-30 phút, publish ngay lên web. Không cần modeling thủ công.

Workflow

  • Quay video 30s-2m bằng điện thoại xung quanh vật thể
  • Extract frames → COLMAP tạo sparse point cloud (SfM)
  • Train 3D Gaussian Splatting (3DGS) — 5 đến 30 phút
  • Xuất file .ply / .splat → load ngay trên web

Use cases

  • Bảo tàng: scan hiện vật, public web 3D viewer
  • Nội thất: virtual tour 3D thay ảnh tĩnh
  • Fashion: scan người mẫu → xem 360° trên product page
  • Di tích lịch sử: số hóa bảo tồn di sản
  • Crime scene: scan hiện trường làm chứng cứ 3D

02 · GIS & Mapping

Drone → Digital Twin 3D trên web

Render hàng tỷ splat realtime, load LOD progressive, fusion LiDAR + ảnh.

Workflow

  • Drone bay + GPS → quay video + LiDAR scan (optional)
  • SfM reconstruct sparse cloud, MVS densify
  • 3DGS train → splat
  • Tiled + LOD để streaming progressive (coarse → fine khi zoom)
  • Render trên web map (Mapbox-like + splat overlay)

Use cases

  • Digital twin đô thị: toàn bộ thành phố dạng 3D trên browser
  • Mining/quarry: đo khối lượng, theo dõi địa hình hàng tuần
  • Nông nghiệp: scan cánh đồng → phân tích cây trồng 3D
  • Disaster response: scan từ drone 5 phút, cứu hộ xem online

03 · E‑commerce & AR

Scan sản phẩm thật → web 3D viewer + AR

Thay modeling $200-2000 bằng scan 30 phút $5. Nhúng splat viewer vào bất kỳ product page nào.

Workflow

  • Đặt sản phẩm trên bàn xoay, quay video 30s
  • Cloud GPU train 3DGS (10-30 phút, ~$5)
  • Compressed .splat ~5-20MB
  • Upload CDN + nhúng <splat-viewer> vào product page
  • AR mode: WebXR cho phép xem sản phẩm trên bàn thật

So sánh

  • Model (glTF): $200-2000, 1-5 ngày, cần artist
  • Splat: ~$5, 30 phút, auto từ ảnh thật
  • Độ chân thực: splat > model (ảnh thật vs. render)
  • Tích hợp Shopify, WooCommerce qua web component

04 · Film & Game Pipeline

Background photorealistic từ scan thực tế

Thay thế mesh modeling bằng splat từ location thật. Hỗ trợ volumetric video 4D.

Game pipeline

  • Scan location thật → splat background cho game
  • Không cần modeling thủ công (environment art)
  • Import Unity/Unreal qua plugin
  • Phù hợp indie game — background đẹp, budget thấp

Film / VFX pipeline

  • Multi-camera array (20+ GoPro) quay diễn viên/ cảnh
  • Per-frame 3DGS → 4D Gaussian splat sequence
  • Camera tự do trong cảnh quay thật (matchmove)
  • Nuke/After Effects composite CG vào splat footage

05 · Medical Imaging

CT/MRI 3D viewer trên web

Không cần phần mềm chuyên dụng (OsiriX, RadiAnt). Bác sĩ xoay/zoom/cắt lát ngay trên browser.

Workflow

  • DICOM từ CT/MRI scanner
  • AI segmentation: phân loại xương, u, mạch máu
  • Extract point cloud từ segmented volume
  • Convert thành splat (mỗi class một màu)
  • Upload hospital intranet → bác sĩ xem 3D trên browser

Use cases

  • Phẫu thuật chỉnh hình: xem xương gãy 3D trước mổ
  • Xạ trị: xác định vị trí khối u so với mô lành
  • Giảng dạy: sinh viên xoay giải phẫu 3D không cần lab
  • Nha khoa: CT jaw → implant planning

06 · Developer Infrastructure

Hệ sinh thái tool xoay quanh Supersplat

Từ CLI pipeline, web component, annotation tool, đến streaming server và version control.

Core tools

  • CLI Pipeline — batch convert, compress, quantize, prune, split
  • Web Component — <splat-viewer> framework-agnostic, AR, lazy load
  • File Converter — .ply ↔ .splat ↔ .ksplat, chạy 100% browser

Advanced tools

  • Annotation Tool — 3D bounding box + segmentation labels → training data
  • Streaming Server — octree LOD, HTTP Range, progressive load
  • Splat Version Control — diff/merge/log cho splat files
